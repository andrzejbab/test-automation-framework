Create MVP web application for small sports club management named Klubster. Frontend: React (with Axios, React Router, Context API), Backend: Django + Django REST Framework, SQLite, JWT Auth, Dockerized.
RESTful API for all features, clean UI, basic styling, ready for deployment (Docker + Heroku/Vercel).

Types of view in Django:
    1. Function-Based Views (FBV)
        Regular Python functions that take a request and return a response.
    2. Class-Based Views (CBV)
        Classes that inherit from Django’s View or its subclasses.
    3. Generic Class-Based Views:
        Pre-built views for common patterns (list, detail, create, update, delete).
    4. API Views (with Django REST Framework):
        ApiView(manual more control) / Viewsets( auto)
